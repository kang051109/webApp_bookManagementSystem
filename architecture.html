1. System Architecture System Architecture

Decoupled front-end/back-end architecture. Vue.js SPA communicates with Spring Boot back-end via RESTful APIs. The back-end follows a layered architecture (Controller / Service / Repository) with manual JDBC persistence to MySQL.

2. Database ER Diagram Entity-Relationship Diagram

4 core tables. users and books are linked through borrow_records (many-to-many), books reference categories via category_id. 

erDiagram
    users {
        BIGINT id PK "primary key"
        VARCHAR username UK "unique"
        VARCHAR password_hash "BCrypt hash"
        VARCHAR email UK "unique"
        VARCHAR full_name "full name"
        VARCHAR role "user / admin"
        TIMESTAMP created_at "created at"
    }

    categories {
        BIGINT id PK "primary key"
        VARCHAR name UK "unique"
        VARCHAR description "optional"
    }

    books {
        BIGINT id PK "primary key"
        VARCHAR isbn UK "unique"
        VARCHAR title "not null"
        VARCHAR author "not null"
        VARCHAR publisher "optional"
        INT publish_year "optional"
        BIGINT category_id FK "references categories"
        INT total_copies ">= 1"
        INT available_copies ">= 0"
        TEXT description "optional"
    }

    borrow_records {
        BIGINT id PK "primary key"
        BIGINT user_id FK "references users"
        BIGINT book_id FK "references books"
        TIMESTAMP borrow_date "default NOW()"
        TIMESTAMP due_date "borrow_date + 14d"
        TIMESTAMP return_date "nullable"
        VARCHAR status "borrowed / returned / overdue"
    }

    categories ||--o{ books : "has"
    users ||--o{ borrow_records : "borrows"
    books ||--o{ borrow_records : "borrowed by"
